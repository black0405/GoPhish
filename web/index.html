The reporting lookups match on Employee Email — a hit copies the report file's own reported value (e.g. soc-support), a miss writes Not Found, and Reported (Yes/No) is No only when both are Not Found. Outcome is built by three checks in order — Submitted Data, then Clicked Link, then the Mimecast Log Type — each filling only the rows the ones before it left unresolved, so the earliest match wins.
